# 💰 Smart Budget Tracker

A clean, modern, and responsive expense and income tracking application built with **React.js**. Designed to manage personal finances effortlessly with real-time balance calculations and keyboard-friendly navigation.

## ✨ Key Features
- **Real-Time Balance Calculation:** Automatically computes total balance, total income, and total expenses using JavaScript array methods (`map`, `filter`, `reduce`).
- **Smart Keyboard UX:** Seamless form navigation using the `Enter` key and automatic input focus powered by React's `useRef` and `useEffect` Hooks.
- **Persistent Storage:** Saves all transactions locally in the browser using `localStorage` so no data is lost on page refresh.
- **Modular Architecture:** Built with clean, reusable functional components (`Balance`, `IncomeExpenses`, `TransactionList`, `AddTransaction`).
- **Modern RTL UI:** Clean card-based interface with clear color-coded indicators for income (green) and expenses (red).

## 🛠️ Tech Stack
- **Frontend:** React.js (Vite)
- **Hooks Used:** `useState`, `useEffect`, `useRef`
- **Styling:** Custom CSS3 (Flexbox, RTL layout)
- **Storage:** Web Storage API (`localStorage`)

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project directory:**
   ```bash
   cd smart-budget-tracker
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
